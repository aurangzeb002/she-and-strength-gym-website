# She&Strength

A website for a made up women only gym in London called She&Strength. We built it as a group project for our Front End Web module at Goldsmiths.

Live site: https://aurangzeb002.github.io/she-and-strength-gym-website/

## Pages

- Home: welcome message and a couple of customer reviews
- About: what the gym is about and the facilities (main hall, MMA studio, pool and training court)
- Prices: the four membership tiers, from £19.99 to £49.99 a month
- Contacts: phone, email and address

## Made with

HTML and CSS. Each page has its own stylesheet.

## How to run

Download or clone the repo and open index.html in your browser.
